# Problem Statement
Tracking daily expenses manually is hard to keep organized, and it's 
easy to lose track of how much you've spent in each category or 
whether you've gone over budget.

This project is a command-line expense tracker that lets a user add, 
view, filter, and delete expenses, set a monthly budget, and see 
category-wise and monthly spending summaries. Data is stored locally 
in JSON files.

Target users: students or anyone who wants a simple way to track 
spending without a banking app or spreadsheet.

Features: add expense, view expenses, category summary, monthly 
total, set budget, delete expense, filter by category/date, top 
spending category, export to CSV.

## Objective

The main objective of this project is to provide a simple and efficient
command-line tool for managing personal expenses. It helps users record
their spending, monitor their budget, and understand their spending
patterns through category-wise and monthly summaries.

## Scope

The expense tracker will allow users to:
- Record expenses with amount, category, date, and description.
- View and filter recorded expenses.
- Calculate monthly and category-wise spending.
- Set and monitor a monthly budget.
- Identify the category with the highest spending.
- Delete incorrect or unwanted expenses.
- Export expense data to a CSV file.

## Data Storage

Expense and budget information will be stored locally using JSON files.
This allows the application to work without requiring a database or
internet connection.

## Technology Used

- Programming Language: Python
- Data Storage: JSON
- Export Format: CSV
- Interface: Command Line Interface (CLI)

## Expected Outcome

The project will provide users with an easy way to record and manage
their daily expenses, track their monthly budget, and understand where
their money is being spent.

## Future Enhancements

Possible future improvements include:
- Graphs and visual spending reports.
- User login and multiple profiles.
- Recurring expense support.
- Budget alerts and notifications.
- Monthly expense reports.
- A graphical user interface (GUI).
- Cloud/database storage.
